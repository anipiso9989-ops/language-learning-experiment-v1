# Language Learning Experiment

Hello! This is an experiment I ran in my senior year of high school. The goal was to see how an extreme stimulus would affect my ability to learn. So, I set this up; I began learning 3 languages in the summer before senior year, and am continuing to do so.

There are multiple files here. 

[The methodology file](methodology.md) talks about my methods; how I actually went about experimenting. 

I've also written down my [daily observations](daily%20observations.md), [analyzed myself weekly](weekly%20analyses.md), and [conducted evaluations monthly](monthly%20evaluations.md).


Any changes are also being recorded, as will my conclusions when I end this experiment (which is when I achieve fluency in all 3 languages). Until then, I'm gonna keep experimenting.
